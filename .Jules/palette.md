# Palette UX & Accessibility Journal

## 2025-02-14 - Visual Hover Tooltips for Icon-Only Buttons
**Learning:** Icon-only buttons with only `aria-label` attributes provide screen reader context but lack hover tooltips for mouse users, creating a cognitive gap. Adding a `title` attribute matching the `aria-label` ensures full accessibility across both visual hover states and assistive technologies.
**Action:** Always provide matching `title` and `aria-label` attributes for icon-only buttons to ensure consistency and usability.
