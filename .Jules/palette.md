## 2026-02-14 - Accessible Client-side Clipboard Copying
**Learning:** For client-side copy interactions (such as the ClipboardCopy hook), standard visual text updates (e.g. changing button labels to "Copied") are completely invisible to screen readers unless politely announced via a visually hidden `aria-live="polite"` element. Additionally, caching the original `aria-label` on mount is critical to prevent rapid successive clicks from overwriting the original label with "Copied" permanently. To prevent DOM pollution, a lazy-initialized singleton/shared live announcer on `document.body` should be used instead of appending a new container per button.
**Action:** Always use a single shared `aria-live` announcer and cache the button's original `aria-label` on mount for copy/clipboard interactions.
