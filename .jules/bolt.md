## 2026-10-10 - Fast-path pattern matching on struct fields in hot path classification
**Learning:** In Elixir data classification functions called heavily across routing and candidate evaluation (like `WindowClassifier.classify/1`), extracting attributes via map lookups and running string operations (`String.trim`, `String.downcase`) on every call introduces significant allocation overhead. Adding pattern-matched function heads for common struct shapes and short-circuiting exact string/atom comparisons (`target == expected`) before string normalization yields significant performance improvements (~44.5% overall speedup; ~6x faster for struct instances).
**Action:** When classifying domain structs on hot paths, add pattern-matched function heads for standard struct attributes and guard token comparisons with `target == expected` before string transformations.
